# Gridland Provinces

A 2 x N grid of lowercase letters. A knight makes a minimum-time tour that visits every cell at least once, starting anywhere. Count how many distinct strings the cells of such a tour can spell.

- **Problem:** https://www.hackerrank.com/challenges/gridland-provinces
- **Input:** P, then for each province: N, then the two rows.
- **Constraints:** Large; see the problem page. The move set is shown as an image on HackerRank and is not reproduced here.
- **Status:** Not verified - returned Wrong Answer and was never made to pass.

## Sample

```
3
1
a
a
3
dab
abd
5
ababa
babab
```

Expected output:

```
1
8
2
```
