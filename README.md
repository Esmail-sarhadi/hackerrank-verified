# HackerRank, verified

Eight solutions to HackerRank problems were generated by an AI assistant in one
session. Three of them survive a compiler, a sample test and an independent
brute-force cross-check. This repository contains those three, plus the harness
that decides which ones qualify.

The other five are documented in [`docs/failure-log.md`](docs/failure-log.md)
with the exact error each one produced. They are not published as solutions,
because a solution that does not pass is not a solution.

## What "verified" means here

Every folder under `solutions/` passes three gates, and all three run in CI:

1. **It compiles.** `dotnet build -c Release`, no errors.
2. **It matches the sample.** The exact output from the problem statement,
   compared line by line after trailing whitespace is normalised.
3. **It matches a second, independent answer.** `tools/crosscheck.py`
   recomputes the answer in Python by enumeration - not by reusing the C# logic -
   and compares. This is the gate that catches a solution which happens to agree
   with one hand-written sample but is wrong in general.

```
$ python tools/verify.py
PASS   even-odd-query                   2 line(s)
PASS   sherlock-and-permutations        2 line(s)
PASS   special-multiple                 3 line(s)

3 solution(s), 3 passed, 0 failed

$ python tools/crosscheck.py
PASS sherlock-and-permutations
PASS even-odd-query
PASS special-multiple

0 problem(s)
```

## The three that survived

| Problem | Approach | Cross-check |
|---|---|---|
| [Sherlock and Permutations](problems/sherlock-and-permutations.md) | Fix the first character as `1`, the rest is `C(n+m-1, n)`; factorials and inverse factorials modulo 1e9+7 | all `n, m` in 1..5 against enumerated distinct permutations |
| [Even Odd Query](problems/even-odd-query.md) | Never compute the power: odd iff `A[x]` is odd, or `A[x]` is even and the exponent is 0, which happens exactly when `A[x+1] == 0` | every length-4 array over `{0,1,2}` without consecutive zeros, every query, evaluated with exact integers |
| [Special Multiple](problems/special-multiple.md) | BFS over remainders modulo `n`; appending a digit maps `r` to `(10r + d) mod n`. The answer is a string, never an integer | `n` in 1..200: divisible, digits only `9`/`0`, no leading zero, and no shorter number works |

## Running it

Requires the .NET SDK (built and tested with 10.0) and Python 3.10+.

```bash
python tools/verify.py       # compile every solution, run its sample
python tools/crosscheck.py   # compare against brute force
```

`tools/verify.py` also accepts a substring to run one folder:

```bash
python tools/verify.py special
```

## Layout

```
problems/<problem>.md   the statement in brief, the sample, and the real status
solutions/<problem>/
  Solution.cs           the submission, copy-pasteable into HackerRank
  solution.csproj       one project per problem, so a build failure names the problem
  sample.in             the input from the problem statement
  sample.out            the expected output from the problem statement
tools/
  verify.py             compile + sample comparison
  crosscheck.py         independent recomputation
docs/failure-log.md     what each rejected attempt actually did
```

`Directory.Build.props` holds the shared build settings, so each
`solution.csproj` is a single line.

## Adding a problem

1. Make the folder, add `Solution.cs`, `sample.in`, `sample.out`.
2. Copy any existing `solution.csproj`.
3. Run `python tools/verify.py`. If it passes the sample, add a cross-check in
   `tools/crosscheck.py`; without one, the solution is not verified, only
   untested against the cases that matter.
